# Maser Media — Deploy to Vercel

Your landing page is **static HTML/CSS/JS**. Deploy to Vercel in under a minute:

---

## Deploy with Vercel (Recommended)

### Option A: Vercel CLI
1. Install: `npm i -g vercel`
2. In the project folder: `cd maser-media` then `vercel`
3. Follow the prompts (login if needed)
4. Your site goes live instantly at `*.vercel.app`

### Option B: Vercel Dashboard
1. Push your project to GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the repo → Deploy
4. Done

**No config needed** — Vercel serves static sites automatically.

---

## Other Options

**Netlify Drop:** [app.netlify.com/drop](https://app.netlify.com/drop) — drag and drop your folder.

**GitHub Pages:** Push to GitHub → Settings → Pages → deploy from `main`.

**Cloudflare Pages:** [pages.cloudflare.com](https://pages.cloudflare.com) — connect repo or upload.

---

## Custom Domain

Add your domain (e.g. masermedia.com) in the Vercel dashboard under **Project Settings → Domains**.
